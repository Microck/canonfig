# Canonfig skills

- [`setup-canonfig`](setup-canonfig/SKILL.md): guided, low-friction setup. It
  inspects first, asks only unresolved questions with short explanations and
  recommended answers, then plans, executes, and verifies the requested Source
  Machine, Follower Machine, or project harness outcome.
- [`install-canonfig`](install-canonfig/SKILL.md): direct installation and
  first-time role establishment.
- [`operate-canonfig`](operate-canonfig/SKILL.md): evidence-first publication,
  synchronization, scheduling, diagnostics, drift handling, and recovery.

Use `setup-canonfig` when the operator wants the skill to lead the workflow.
Use the narrower install or operate skill when the requested command path is
already known.
