---
title: Canonfig
description: A deterministic, one-way configuration synchronizer with bounded AI assistance.
---

Canonfig keeps declared AI agent configuration aligned across machines. One
**Source Machine** publishes immutable, authenticated **Profile Revisions**.
Each **Follower Machine** plans, applies, and verifies the revision selected for
its **Machine Profile** and **Follower Groups**.

<Callout title="The authority boundary" type="info">
  Followers never publish upstream state. Discovery and Configuration Agent
  output become Profile Change Proposals; publication is always explicit.
</Callout>

## Non-goals

Canonfig does not provide bidirectional synchronization, automatic credential
copying, silent conflict resolution for modified skills, whole-home-directory
backup, or a hosted fleet control plane. It also does not guarantee rollback
for third-party installers.
