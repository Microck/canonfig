---
title: Canonfig
description: Keep Claude Code, Codex, and other AI agent configuration the same on every machine you use, published from one machine you control.
---

Canonfig copies your AI agent configuration (instruction files, settings keys,
MCP servers, skills, and tools) from one machine to others. You declare what to
share in a **Machine Profile** on the **Source Machine** and publish it as a
signed **Profile Revision**. Each **Follower Machine** checks that Profile
Revision, applies it, and verifies the result. Follower Machines never send
changes back.

To see the commands and their output before you install anything, try the
[interactive demo](https://canonfig.micr.dev). It runs on simulated data.

## What Canonfig does not do

- It does not sync in both directions. A change made on a Follower Machine stays there or is overwritten, depending on the resource.
- It does not copy credentials, logins, or the trust decisions each client asks you to make.
- It does not back up your home directory.
- It does not run a hosted service. Your Source Machine serves the Profile Revisions.
- It does not guarantee that a third-party installer can be rolled back.

To learn which machine owns what and what one run can roll back, read
[How Canonfig works](/explanation/architecture).
